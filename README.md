# My Resume Website

A personal resume website built using **HTML and CSS** to showcase my professional profile, technical skills, education, internships, projects, certifications, achievements, hobbies, and contact information.

## 🌐 About the Project

This project is a simple and responsive personal resume website created using basic web technologies.

The website contains:

* Personal profile
* Professional summary
* Technical skills
* Internship & experience details
* Projects
* Educational qualifications
* Certifications
* Activities & honors
* Online profiles
* Hobbies
* Contact information

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Aslam-sk/my-resume-website.git
```

2. Open the project folder:

```bash
cd my-resume-website
```

3. Open `index.html` in your web browser.

You can also use **VS Code Live Server** to run the website locally.
